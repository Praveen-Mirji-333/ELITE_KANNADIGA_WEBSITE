========================================================
1. DESIGN PHILOSOPHY
========================================================

The application should combine:

- Professional SaaS dashboard
- Esports tournament management platform
- Modern admin control center
- Clean enterprise UI
- Premium dark gaming identity

Think:

Linear + Vercel + modern esports operations dashboard

NOT:

- Neon gaming website
- Cyberpunk UI
- Overly colorful gaming dashboard
- Generic Bootstrap admin panel
- Excessive glassmorphism
- Excessive gradients
- Over-designed gaming interface

3. Fast navigation
4. Clear actions
5. Consistency
6. Visual hierarchy
7. Professionalism

The gaming identity should come from the branding, typography, iconography and restrained gold accents — NOT from excessive visual effects.
